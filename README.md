# 词间 Wordlane

一个中文界面的英语学习网页应用，围绕你的 **2027 年 6 月大学英语四级**、**《新时代大学商务英语综合教程 2》**和 **Everything I Know About Love** 组织学习。

## 运行

需要 Node.js 20.16+（建议 Node.js 22 或 24）。在本仓库目录执行：

```sh
npm ci
npm run dev
```

启动后，在运行这两个命令的电脑上用浏览器访问 `http://localhost:3000`。可通过 `PORT=8080 npm start` 改端口。本项目尚未部署到公网；云环境内的进程不会自动成为你的电脑可访问的网站。

## 能做什么

- 今日新词任务、优先到期复习、单词卡、音标、语境例句、浏览器英语发音、拼写练习。
- 根据自评分数安排 10 分钟 / 1 天 / 3 天 / 7 天及更长间隔的复习。选择“再学一次”还会在本轮再练一次。
- 保存备考月份、具体考试日期、目标词汇量、每日新词量与学习时间；具体考试日期默认留空，未假定官方考试日。
- 内置日常生活、四级精选、商务英语共 **90 个单词**。4500 是可调整的备考目标，不代表已内置完整的四级词库。
- 课本和阅读资料架：支持 PPTX、DOCX、EPUB、含文字的 PDF、TXT、MD，以及直接粘贴文本。EPUB 按原书目录选章；每章的词单与例句分别保存，学习进度共享。课本入口已接入用户提供的 Unit 1 三份课件及两份例句资料，仅覆盖这批资料中的内容；已上传的个人阅读书也可加载到当前环境的本地资料库，不从外网下载原书。
- 导入材料后提取最多 80 个候选词，匹配内置释义；其他词由你补充释义。按资料分别保存包含单词的原文句子，从不同资料学习时显示对应语境；不凭空生成词义或原句译文。候选词以词频和内置匹配排序，仍需人工挑选。
- 更新资料可重新导入到同一资料入口，替换关联词单；已存在单词的学习记录保留。相同单词在不同来源间共享进度。
- 单词搜索、收藏、自建单词与编辑、自评熟悉率、近七天学习记录、累计学习天数、连续学习天数。
- 数据保存在当前浏览器的 localStorage。可导出 JSON 备份，在另一设备确认后恢复；没有云账号同步。
- 首次成功联网加载、Service Worker 缓存完成后，支持离线复习和本地资料解析；语音能否离线使用取决于系统语音包。

## 资料导入

1. 打开“我的学习资料”。
2. 在课本或 *Everything I Know About Love* 卡片上选择“导入章节”。
3. 选择自己的 EPUB / PDF / 文本文件，或粘贴一章、一篇文章；选择资料类型，可记录原文网址。
4. EPUB 先选择章节，再提取并勾选想学的词；未匹配词填写释义后再勾选。
5. 保存后即可从这份资料开始学习，或在“我的词库”按来源筛选。

文件在浏览器本地解析，不上传服务器。原文件不保留在存储中，只保留你选择的词汇、例句及来源信息。单次文件导入最多 20 MB；PDF 最多 200 页；文本每次最多 12 万字符；EPUB 可按章节导入，解压后文档资源合计最多 40 MB。扫描件需先 OCR。网址只作来源记录，不自动抓取网页，也不自动连接学校平台、网盘或杂志订阅。

## 测试

无需额外依赖的核心测试：

```sh
npm test
```

浏览器流程测试需要 Python、Playwright、PyMuPDF 和 Chromium，先启动应用，然后执行：

```sh
python tests/browser_smoke.py
```

默认使用 `/usr/bin/chromium`；可通过 `CHROMIUM_PATH` 指定浏览器路径。测试覆盖实际学习评分、间隔安排、刷新后进度、拼写、资料选词、PDF 解析、备份恢复、离线刷新及手机布局。截图和测试输出只写入被忽略的 `.test-artifacts/`。

## 数据与使用提醒

更换浏览器、清除站点数据、使用隐私窗口可能丢失本地记录，建议定期导出备份。发音由浏览器和系统语音提供；不支持时界面会提示。键盘可用空格揭晓释义，用 1—4 评分。

本项目为原生 JavaScript、CSS 和 Node.js 静态服务；PDF 解析使用固定版本的 PDF.js，EPUB 的 ZIP 解压使用 fflate。无需 API Key、数据库或登录。

## 个人 EPUB 阅读资料库

当前云环境已从用户上传的 *Everything I Know About Love* EPUB 解析出 43 个阅读部分（42 个正文章节及致谢），存放在 `.local/reading-book.json`。这是个人运行数据，已加入 `.gitignore`，不包含在源代码提交中。

当个人资料库可用且这本书尚未导入时，首次打开应用会从第一章匹配并建立起步词单；不会覆盖已有的阅读词单或学习记录。在“我的学习资料”中选择该书的“选择书中章节”，可以继续导入其他章节。通过“学习章节”切换章节词单，或选择全部已导入章节。

阅读词汇释义来自应用自行编写的辅助词表，只有实际出现在章节中、且被匹配或由用户确认的词才会加入。原文例句不自动翻译，避免把未核实的翻译当作书中内容。

个人书籍全文不会写入 JSON 学习进度备份，备份只含选入的词和例句。因此在另一台设备或纯 Git 检出中，需要重新选择自己的 EPUB。云环境快照可以保留 `.local` 文件，但源代码仓库不保留这份个人文件。服务没有公开部署。

真实 EPUB 流程检查（需要当前环境的个人阅读资料库）：

```sh
EPUB_PATH='/path/to/your-book.epub' python tests/epub_smoke.py
```

## 按课堂资料学习

本次五份老师资料已整理到个人运行数据 `.local/course-library.json`，其原始文字提取记录为 `.local/teacher-sources.json`。这些文件均被 Git 忽略。内容包括 Unit 1-1、Unit 1-2、Unit 1-3 三份课件（共92页），以及 U1 Text 1 生词例句、W5-1 更多例句两份 Word。

“课堂同步”提供五个按来源划分的入口，包含 **98 个去重词条，其中40个是语法术语**。跨课次重复单词只存一份进度，同时保留不同课次的原句与位置；已学过的阅读词和此前自行导入的课本词不会被清空。

- 单词卡显示资料原句、文件名及幻灯片页码 / Word 非空段落编号，区分“资料原译”和“整理译文”。中文词义与学习提示是整理结果，不当作老师原话。
- 在词库点开一个课堂词，可展开其原始例句和语境。语法术语或只列出名称的词不编造原文例句。
- 练习清单由用户完成后自行勾选，状态可备份；不会自动执行或代答课件中的任务。
- 核对提示解释 seamless / seamlessly、pitch / pitch in、oligopoly 等区别和资料中的明显笔误。原文查看区保留原写法。
- 课件提到的外部视频、Text 2、教材习题页和课外文章未随本次文件提供，不表示已读取或完成。
- 今后可在资料架直接导入 PPTX / DOCX，提取文字后按页或整份选词。PPTX 最多300页，仅解析幻灯片中的文字，不解析图片、视频和备注；DOCX 解析正文和表格文字，不做图片 OCR。旧版 `.ppt` / `.doc` 需先另存为新格式。

个人课堂内容通过可选 `/course-library.json` 接入。纯 Git 检出不会包含老师的原文件或这份整理数据，但通用课堂与Office导入代码可正常运行。若需保留当前资料，请保留环境快照与学习备份，不要将个人课件提交到公开仓库。

课堂功能测试（需要当前环境的个人课堂资料）：

```sh
python tests/classroom_smoke.py
```

它验证全部引文的位置、真实PPTX/DOCX解析、语法筛选、课堂练习与任务记录、重复同步不清空学习进度，以及原有书籍数据保留。

## 浏览器试用发布包

`npm run build` 生成 `dist/` 静态网页，可部署到 GitHub Pages 等静态站点，并支持仓库子路径。公开发布包只包含程序和通用词库，自动排除 `.local` 中的个人书籍、老师资料、学习进度和临时访问密钥；在线版本的个人资料需要用户在浏览器本地重新导入。

已准备 `.github/workflows/deploy-pages.yml`，仅允许手动触发发布，没有设置 push 时自动发布。用户已确认向 GitHub 仓库写入代码及公开上线网站。当前连接调用 Pages 读取和创建接口均收到 `403 Resource not accessible by integration`，网站尚未上线；需在 GitHub 仓库 Settings → Pages 中启用 GitHub Actions 来源，再手动运行此工作流。仓库目前为私有仓库，能否启用 Pages 取决于账户方案；不要为发布擅自改成公开仓库。

`npm run trial` 是另一种可选的临时受保护代理方式，默认绑定本机 3001 端口、转发已有的 3000 端口应用，使用随机访问密钥和 HttpOnly / Secure Cookie，最长运行3小时。它本身不提供公网入口；当前环境尝试 Cloudflare 临时通道时收到403，未建立外网试用网址。访问密钥写入被忽略的 `.local/trial-session.json`，不要提交该文件。
