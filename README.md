# 此刻 FM

`/cike/` 是一个中文心情电影与歌曲推荐应用，原英语学习首页保留。输入想法，选择「被理解」或「换个心情」，通常获取 2 部电影和 2 首歌（少量语言曲目不足时按实际数量展示）；支持类型筛选、外部平台搜索和浏览器本地收藏。

片单包括 50 部电影（42 部文艺片）与 50 首歌曲（45 首外语歌），支持英语、法语、日语、韩语、西班牙语、葡萄牙语和意大利语。默认筛选文艺片与外语歌，可选择经典片、其他语言或不限，完整片单可分页浏览；「换一组」在符合心情的作品中轮换。

推荐基于精选作品的关键词与标签匹配，没有调用 AI 或外部推荐 API。收录的是作品名称、创作者、所选版本的年份、主题标签与原创推荐短评，不包含电影、音乐文件或歌词；年份使用作品或所选录音版本的首次发行年。经典与文艺为编辑精选分类，不代表官方榜单。无法识别心情时会明确提示并提供生活与希望主题作品。输入不保存、不上传；收藏保存在 localStorage。外部搜索仅发送作品名称，不发送用户想法。视觉封面为原创 CSS 图案，并非官方海报。

运行：Node.js >=20.16，执行 `npm ci`、`npm run dev`；可用 `PORT=3002 npm run dev` 指定端口。`npm run build` 生成包含 `cike/` 应用的 `dist/` 静态资源。启动后打开 `/cike/`。`python tests/mood_smoke.py` 验证此刻 FM 的推荐、筛选、收藏及手机布局。原英语学习模块源码保留，`npm test` 检查原模块及新增片单、心情匹配、语言筛选和轮换逻辑；浏览器流程由 `tests/mood_smoke.py` 验证。

# 词间 Wordlane

一个中文界面的英语学习网页应用，围绕你的 **2027 年 6 月大学英语四级**、**《新时代大学商务英语综合教程 2》**和 **Everything I Know About Love** 组织学习。

## 运行

需要 Node.js 20.16+（建议 Node.js 22 或 24）。在本仓库目录执行：

```sh
npm ci
npm run dev
```

在线试用：<https://sugariboo-m.github.io/-my-first-project/>。

本地启动后，在运行这两个命令的电脑上用浏览器访问 `http://localhost:3000`。可通过 `PORT=8080 npm start` 改端口。云环境内的进程不会自动成为你的电脑可访问的网站。

## 能做什么

- 今日新词任务、优先到期复习、单词卡、音标、语境例句、浏览器英语发音、拼写练习。
- 根据自评分数安排 10 分钟 / 1 天 / 3 天 / 7 天及更长间隔的复习。选择“再学一次”还会在本轮再练一次。
- 保存备考月份、具体考试日期、目标词汇量、每日新词量与学习时间；具体考试日期默认留空，未假定官方考试日。
- 内置日常生活、四级精选、商务英语共 **90 个单词**。4500 是可调整的备考目标，不代表已内置完整的四级词库。
- 课本和阅读资料架：支持 PPTX、DOCX、EPUB、含文字的 PDF、TXT、MD，以及直接粘贴文本。EPUB 按原书目录选章；每章的词单与例句分别保存，学习进度共享。课本入口已接入用户提供的 Unit 1 三份课件及两份例句资料，仅覆盖这批资料中的内容；已上传的个人阅读书也可加载到当前环境的本地资料库，不从外网下载原书。
- 导入材料后按水平过滤并分页查看候选词，默认选择前80个适合且匹配释义的词，每轮最多保存500词。匹配已有释义或WordNet英文义项；其他词由你补充释义。按资料分别保存包含单词的原文句子，从不同资料学习时显示对应语境；不凭空生成词义或原句译文。候选词先排除基础词和认识清单，优先显示明确不熟的词；词频只在未过滤词中参与排序。疑似仅作专名使用的词不默认选中，仍需人工核对。
- 更新资料可重新导入到同一资料入口，替换关联词单；已存在单词的学习记录保留。相同单词在不同来源间共享进度。
- 单词搜索、收藏、自建单词与编辑、自评熟悉率、近七天学习记录、累计学习天数、连续学习天数。
- 数据保存在当前浏览器的 localStorage。可导出 JSON 备份，在另一设备确认后恢复；没有云账号同步。
- 首次成功联网加载、Service Worker 缓存完成后，支持离线复习和本地资料解析；语音能否离线使用取决于系统语音包。
- 探索练习：每日五词挑战、按课本或阅读词源生成的语境填空、答错自动收集且答对后移出的错词本、成长等级与七枚学习成就。练习结果单独记录，不改变单词卡的自评复习安排；同一天重复答对同一个词不重复奖励成长值。
- 词典资料馆：已导入 WordNet 3.0 的 **147,306 个英文词头 / 短语、206,941 个词义关联**，显示英文原释义、原例句、同义词与源义项编号，并提供牛津学习词典、剑桥英汉词典、Merriam-Webster 的官网查询链接。可从单词卡查词，再选择一个义项加入自建词库。

## 资料导入

1. 打开“我的学习资料”。
2. 在课本或 *Everything I Know About Love* 卡片上选择“导入章节”。
3. 选择自己的 EPUB / PDF / 文本文件，或粘贴一章、一篇文章；选择资料类型，可记录原文网址。
4. EPUB可选择整本、勾选多个章节，或仅筛选当前预览部分；统一筛词后选择要学的词，未匹配词补充释义再勾选。
5. 保存后即可从这份资料开始学习，或在“我的词库”按来源筛选。

文件在浏览器本地解析，不上传服务器。原文件不保留在存储中，只保留你选择的词汇、例句及来源信息。单次文件导入最多 20 MB；PDF 最多 200 页；每轮所选正文合计最多300万字符、500个文字部分；章节预览最多显示12万字符，批量分析仍使用完整原文。EPUB解压后文档资源合计最多40MB。扫描件需先 OCR。网址只作来源记录，不自动抓取网页，也不自动连接学校平台、网盘或杂志订阅。

## 探索练习与学习记录

“探索练习”从现有学习词库出题，材料语境使用用户导入的原句；语法名称等课堂术语不加入每日选择题。每日五词题目在词库相同、日期相同时保持一致；语境填空要求补回资料原句中的表达，并非声称其他表达在语法上一定错误。

成长值按每天每词首次评分 5 点、每天每词首次答对练习 3 点计算。重复练习仍记录实际作答次数，但不会重复发放成长值；成就根据真实学习、资料关联和挑战记录计算，没有虚构的排名或其他用户。探索页的连续学习天数包括单词卡和探索练习；首页原有连续天数按单词卡评分统计。

练习记录与错词本保存在原来的 `wordlane.v1` 数据中，旧版备份无需转换即可恢复。新备份包含练习与词典收词来源，不包含整个 WordNet 数据库。未做完的题组不会标记为完成，已作答结果仍保存。手机底栏保留今日学习、探索练习、词典、复习和更多；课本、书籍、词库、统计与设置均可从“更多”进入。

## 词典来源、范围与许可

WordNet 3.0 是英语词汇数据库，不是英汉词典，也不等于内置完整四级词库。英文释义、同义词、例句来自原始数据，中文学习释义来自应用整理或用户自己的确认；页面分别标明。可将查询词还原为原形，但原始数据有精确词条时优先使用精确词条。

数据库由官方归档生成：<https://wordnetcode.princeton.edu/3.0/WordNet-3.0.tar.gz>。导入脚本固定归档的 SHA-256（见 `scripts/import_wordnet.py`），读取词义、同义词及例句，保留源义项 ID；未打包语义关系指针等其他数据库字段。词条以字母分区保存到 `dictionary/`，JSON 合计约39 MiB，浏览时按需下载分区，不在首页加载全库。成功查询后分区由 Service Worker 缓存，离线可查已经缓存的分区；尚未缓存的分区需要联网。

WordNet 3.0 Copyright 2006 by Princeton University. All rights reserved. 完整许可和免责声明见 [`dictionary/LICENSE.txt`](dictionary/LICENSE.txt)，每个数据分区也保留相同许可。这里的来源说明不表示原作者对本应用的认可或背书。

牛津、剑桥与韦氏以官网查询入口提供，未复制它们的整库、未接入付费 API，也未将应用整理的中文解释标为这些词典的内容。打开外部入口会将所查词交给对应官网，使用其服务和页面规则。

需要从相同官方归档重新生成词典时执行：

```sh
python scripts/import_wordnet.py /path/to/WordNet-3.0.tar.gz
npm run build
```

省略文件参数时，脚本复用 `/tmp/wordlane-wordnet-3.0.tar.gz` 或通过 HTTPS 下载官方归档，先校验散列再生成；正常安装和 CI 使用已提交的数据分区，不重复下载。

## 水平自测、认识清单与整本筛词

首页提供“测测我的水平”和“调整筛选”。默认跳过前3500个常用词头及其可识别词形，作为高中及以前常见基础词的近似过滤。常用度由 wordfreq 3.1.1 英文频率顺序与WordNet词头交集重排得到，不是中国高中官方词表；与具体教材、学生是否掌握不能一一对应。范围可改为0、1000、2000、3500、6000，或关闭基础过滤。普通基础过滤保留既有复习，手动标记“已认识”会将该词移出自动推荐与复习；所有旧评分和来源关联仍保留。

30题自测按五个常用度分层抽样，每层6题，题库中文释义为应用整理内容。选择“不认识/不确定”按未掌握处理，未完成的进度可刷新后继续。连续达到每层5/6的层级用于建议过滤范围；完成后点击“应用建议”才更新个人范围。结果显示分层答题情况和筛选建议，不将小样本、选择题或猜测换算成精确词汇量、CEFR证书或四级预测分数。答错和不确定的词加入明确不熟清单，优先保留；答对的样本加入认识清单，均可手动调整。

认识与不熟清单按词头归并，例如 children/child、studied/study、memories/memory。词形还原使用WordNet不规则表和常见规则，属于启发式规则，可能存在多义或词形歧义；短语独立判断，不能因为单个组成词简单就自动当作认识。词卡、词条详情和候选词提供“已认识/还不熟”的调整入口；记忆自评失败与练习错词也会进入不熟清单。

EPUB、PPTX、长Word、PDF及长文本可选全部或多选部分，逐部分统计而不拼入预览框；超过范围提示分批选择，不悄悄截断。整本词汇按词头去重，每章分别保存入选词的原句/语境；同章再次导入累积词条，旧学习记录保留。候选词每页80项，可搜索全部章节、查看被过滤词和手动加回；分页保留选择和自填释义，默认最多推荐80词，每轮最多保存500词。手动加回被过滤词会将其标为不熟。候选来源中的英文释义采用WordNet的首个义项，不保证就是当前语境所用义项，允许修改并保留原始来源供核对。

新增生成资产：`frequency.js` 包含20,000个重排常用度词头和WordNet词形表；`selection-lexicon.js` 为按频率选取的30,000词头的WordNet首义项子集，首次筛词按需加载，后续可缓存使用，网络失败仍能匹配已有释义并允许手动填写。频率派生数据以CC BY-SA 4.0分发，完整来源及原作者/语料署名在 `frequency-DATA-NOTICE.txt`；WordNet原始许可也保留在子集文件和 `dictionary/LICENSE.txt`。常规CI和运行无需Python新依赖，只有重新生成这些已提交资产时才需要安装 `wordfreq==3.1.1` 并运行 `python scripts/build_frequency.py`。
