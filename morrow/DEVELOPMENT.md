# 小满 · 个人记账与存钱原型

需要 Python 3 和 Node.js（验证使用 Node 24、Python 3.12），无第三方依赖。

在仓库目录运行 `npm start`，使用端口 3000；运行 `npm test` 验证金额与 CSV 导入。

支持响应式总览、按月收支、分类统计、手动储蓄余额、目标进度、模板 CSV 导入去重、JSON 备份和替换恢复。CSV 使用 UTF-8，表头为 `日期,类型,分类,金额,账户,备注`，日期为 YYYY-MM-DD，类型为收入或支出。完全相同的导入记录会去重；两笔确实相同的交易请手动新增区分。

数据存储在当前浏览器 localStorage。无登录、加密、云端同步或真实金融账户接入。不同浏览器、设备、站点地址之间不会自动共享数据。请定期导出备份。手动记账不改变储蓄余额。分类分析仅基于选择月份的支出。

支付宝小荷包、微信和银行账户连接尚未实现；须核实各平台官方只读接口、个人接入资格及授权范围，不能通过收集用户密码或支付凭据替代官方授权。未来账户连接不得授予转账、支付或扣款权限。
